# 株式会社Mars Online ｜ 事業計画書 2025

元の Word 文書を、**項目企画書（プロジェクト企画書）らしいレイアウト**に再設計したものです。
本文の内容は原文に忠実で、構成・体裁のみを刷新しています。

## 成果物

| ファイル | 内容 |
|---|---|
| `事業計画書_MarsOnline_2025.docx` | 再設計版（編集可能な Word 文書、A4 縦 / 全8ページ） |
| `事業計画書_MarsOnline_2025.pdf` | 確認用 PDF |
| `design/build.js` | 文書を生成するスクリプト（docx-js） |
| `design/assets/` | 表紙アート・ビジネスモデル図（原文書から抽出） |

## ページ構成

| P | 内容 |
|---|---|
| 1 | 表紙（原文書の表紙アートをフルブリード＋社名を重ねる） |
| 2 | 目次 CONTENTS（01–04・英文サブタイトル・ページ番号） |
| 3 | 01 会社概要 — 会社基本情報テーブル／事業ドメイン／CORE BUSINESS |
| 4 | 02 業界動向 — POINT 1–3＋広告フォーマット一覧表 |
| 5 | 03 業界展望 — POINT 4–5＋OUTLOOK |
| 6 | 04 事業展開計画 — 日本市場を選ぶ理由（9項目）／POINT 1–2／短期・中長期目標 |
| 7 | 04 続き — POINT 3／広告・付加価値サービス／当社のビジネスモデル（FIG.01） |
| 8 | 裏表紙（社名・所在地・事業領域） |

原文書では「業界の現状と展望」が1章にまとまっていましたが、原文書自身の目次が
`02 業界動向 / 03 業界展望` の2章立てだったため、5つの側面を
1–3＝現状（02）、4–5＝展望（03）に振り分けています。

## デザイン

配色は元の表紙アートから抽出しています。

| 用途 | 値 |
|---|---|
| プライマリ（ネイビー） | `#035891` / 濃 `#02385C` |
| アクセント（シアン） | `#18E5E9` / 文字用 `#0A7F92` |
| 図版ブルー | `#2E5F7F` |
| 背景・罫線 | `#F3F7FA` / `#E9FBFC` / `#D6E0E8` |

書体は和文 游ゴシック（Yu Gothic）＋欧文 Arial。
共通パーツとして、章扉バンド・見出しバー・POINT カード・比較2カラム・
チップグリッド・コールアウト・図版キャプション（FIG.xx）・
ヘッダー／フッター（ページ番号付き）を定義しています。

cd design

npm run build      # → ../事業計画書_MarsOnline_2025.docx
